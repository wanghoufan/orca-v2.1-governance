# 迁移整理提示词｜老项目一句话归位

```text
【迁移整理】

模板文件夹已拷进本项目。你是整理工，不改业务逻辑。

1. 按模板目录结构把当前项目文件分类归位：该进docs的进docs；模板无 scripts，不新建，业务原地不动。
2. 铁律：搬了会broken的一律不搬，留原地+记一条映射（原路径→治理引用路径）。
3. 基线（默认干，不用问人）：装依赖（pnpm/npm install）→跑 lint/ts-check/test→记 PASS/FAIL。lint挂了边修边继续，不拿lint卡dev启动；node_modules缺失就装，不要问。
4. 有UI的项目：有 UI 必目检（首页+一个详情页），无 computer-use 条件时 curl＋截图替代并记账；dev起后台+curl验状态码，截图路径记下来。
5. 输出《项目文件归位表》：已归位/留原地+原因/引用路径。留原地不算失败。
6. 写 GOVERNANCE_VERSION（内容：版本以本仓库Git历史为准），完事按编排者提示词开工。
```
